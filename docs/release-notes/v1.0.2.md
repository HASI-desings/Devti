## Devti 1.0.2 — the window fits your screen

**On laptops, the bottom of Devti's window was cut off.** On screens like 1366×768, the
window was taller than the screen, and the bottom of the sidebar and of each page couldn't be
scrolled to. The window now fits the screen, and the sidebar and pages scroll inside it.

This release also includes 1.0.1's fix for the crash at startup on Linux desktops with a keyring.

### Download

| You have | Get |
|---|---|
| Windows 10/11 | `Devti_1.0.2_x64-setup.exe` (or the `.msi`) |
| Ubuntu, Debian, Mint | `Devti_1.0.2_amd64.deb` → `sudo apt install ./Devti_1.0.2_amd64.deb` |
| Fedora, openSUSE | `Devti-1.0.2-1.x86_64.rpm` |
| Any Linux | `Devti_1.0.2_amd64.AppImage` → `chmod +x` and run it |
| Android 8+ | `devti-v1.0.2-android.apk` |

Everything else is as in [1.0.0](https://github.com/HASI-desings/Devti/releases/tag/v1.0.0).
The Android APK is signed with a temporary key (see docs/RELEASING.md).
