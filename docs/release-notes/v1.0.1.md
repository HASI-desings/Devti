## Devti 1.0.1 — fixes a startup crash and a cut-off window on Linux

**If Devti 1.0.0 closed straight away on your Linux desktop, this release fixes it.**

On desktops that run a keyring (GNOME Keyring or KWallet, as on Ubuntu, Mint, Fedora and most
others), Devti 1.0.0 crashed at startup with "Cannot start a runtime from within a runtime".
The keyring library and Devti were both trying to drive background work on the same thread.
Devti now talks to the keyring on a separate thread. A rule that runs a saved command had
the same problem and is fixed too. Test machines have no keyring, which is why it slipped
through.

**The window no longer runs off the bottom of smaller screens.** On laptops (for example
1366×768), the bottom of the sidebar and of each page was cut off and couldn't be scrolled to.
The window now fits the screen, and the sidebar and pages scroll inside it.
