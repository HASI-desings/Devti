## Devti 1.0.0 — all your devices, one living system

The first release of Devti: free, open source and local-first. Your devices connect directly
to each other over encrypted QUIC (TLS 1.3, pinned keys, PAKE pairing). There are no accounts
and no cloud.

### Download

| You have | Get |
|---|---|
| Windows 10/11 | `Devti_1.0.0_x64-setup.exe` (or `Devti_1.0.0_x64_en-US.msi`); the `devti` command is `devti-cli-v1.0.0-windows-x64.exe` |
| Ubuntu, Debian, Mint | `Devti_1.0.0_amd64.deb` → `sudo apt install ./Devti_1.0.0_amd64.deb` |
| Fedora, openSUSE | `Devti-1.0.0-1.x86_64.rpm` → `sudo dnf install ./Devti-1.0.0-1.x86_64.rpm` |
| Any Linux | `Devti_1.0.0_amd64.AppImage` → `chmod +x` and run it |
| Android 8+ | `devti-v1.0.0-android.apk` |
| iPhone / iPad | Build it yourself with Xcode — see `ios/README.md` |
| A plugin to try | `devti-plugin-link-cleaner-v1.0.0.zip` (unzip, then Plugins → Add a plugin) |

Check downloads against `SHA256SUMS.txt`. The Windows and Linux builds are unsigned, because
code-signing certificates cost money. On Windows choose **More info → Run anyway**.

### What's in it

- **Pairing and trust:** QR code or 6-digit code, the same code shown on both screens, roles
  and per-device permissions, an activity log, and a one-click kill switch.
- **Continuity:** clipboard both ways, resumable files of any size, phone notifications with
  actions and replies, Do Not Disturb everywhere, find my device, and battery history.
- **Control:** your phone as touchpad, keyboard, media remote and shortcuts deck. Mirror and
  control an Android phone. A local API and the `devti` command.
- **Screens:** show a screen or one window on another device, use a tablet as a touch screen,
  and one keyboard and mouse across computers (X11 and Windows).
- **Bluetooth:** accessories recognised automatically, with control panels built from device
  profiles. Vendor controls need Linux for now, and untested profiles are labelled.
- **Communication:** texts and calls from an Android phone on the computer, continue a link or
  video where you left off, and the phone as the computer's microphone, sound source or webcam.
- **Automation:** rules for devices, batteries, accessories, time, apps, networks, and your
  phone walking away.
- **Reach and extensibility:** reconnect from anywhere through Tailscale, WireGuard or a
  forwarded port; browse and download shared folders; sandboxed WebAssembly plugins.

### Honest notes

- Android: notifications, screen sharing and control need the permissions Android asks for.
  Some phone makers stop background apps, so set Devti's battery use to *Unrestricted*.
- iPhone: Apple allows apps to connect only while they're open, and doesn't let any app read
  texts or calls or share its screen. Details are in `ios/README.md`.
- Bluetooth vendor profiles and phone features were tested against simulators and protocol
  documentation, not every real model. `docs/QA.md` lists exactly what was verified and how.
